## 3. 覆盖状态说明

- **CAP**：项目 `4.1/4.2/4.3/4.4/4.6` 已系统覆盖，但需持续排查“三选二”等简化表述。
- **FLP**：仅在 `4.4.1` 中提及，缺少完整的形式化模型与教学证明。
- **PACELC**：在 `4.2/4.3/4.6` 中部分覆盖，缺少真实系统分类表与形式化规约。
- **Linearizability**：为当前主要缺口。`4.6` 虽有语义定义，但未与 Sequential/Causal/Eventual 一致性建立严格层级，也未给出可线性化判定算法。

## 4. 常见表述修正清单

| 错误表述 | 正确表述 |
|---|---|
| CAP 三选二 | 分区不可避免时需在 C/AP 间选择；无分区时 C 与 A 可同时满足 |
| 放弃分区容忍性 | 真实分布式系统无法放弃 P |
| CA 系统 | 仅适用于非分布式或分区极罕见场景 |
| CAP 的 C 等于 Serializability | CAP 的 C 指 Linearizability，与事务隔离级别不同 |
