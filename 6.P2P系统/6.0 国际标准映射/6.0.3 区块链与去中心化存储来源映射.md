## 3. 覆盖状态说明

- **Bitcoin**：在 `6.1.3/6.1.5` 中部分覆盖，但缺少与白皮书原文章节的对照及形式化安全分析。
- **HotStuff**：正文几乎未覆盖，为当前主要缺口；其 BFT 共识机制与区块链场景高度相关，计划在 Phase 2 补充。
- **libp2p / IPFS**：在 `6.0.1/6.1.1/6.1.3` 中仅简单提及，缺少 multiaddr、CID、bitswap、gossipsub 等条款级映射。
- **BEP 52 v2**：Draft 状态，项目 `6.0.1` 已覆盖部分 BitTorrent 协议细节，但 v2 的 Merkle torrent 与 hybrid torrents 尚未系统映射。
- **Chord / Kademlia / Sybil 防御**：细节覆盖缺口，详见 [6.0.1 BitTorrent 与 DHT 协议标准映射](6.0.1%20BitTorrent%20与%20DHT%20协议标准映射.md)，计划在 Phase 2 补齐。
