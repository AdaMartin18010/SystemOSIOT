## 4. 关键覆盖缺口（Phase 2 待补齐）

1. **IoT 设备安全能力基线未系统化**：`3.1 知识梳理/3.1.1 基本概念.md` 的安全模型仅为四元组示意，未按 NIST SP 800-213A 的七项技术能力与非技术支持能力逐条映射。
2. **安全等级到控制措施的映射缺失**：`3.2 批判分析` 缺少 IEC 62443-2-1:2024 安全等级 SL0–SL4 与 IoT 嵌入式系统控制措施的映射表。
3. **安全运行时语义缺失**：`3.7 系统运行时语义` 未覆盖安全状态机、固件更新运行时模型、安全事件日志与异常检测机制。
4. **工业 IoT / IACS 场景未覆盖**：项目以通用 IoT 与 RTOS 为主，缺少工业控制系统（IACS）资产所有者安全计划视角。
