## 4. 关键覆盖缺口（Phase 2 待补齐）

1. **Matter 协议栈完全缺失**：项目 `3.x` 与 `8.x` 均未系统覆盖 Matter 的设备类型、Cluster 模型、Fabric、Commissioning、Attestation、CASE/PASE 会话等内容。
2. **Thread mesh 网络机制缺失**：`3.1` 与 `3.5` 的协议栈层次表未包含 Thread 网络层，也未说明 Matter over Thread 的协议组合。
3. **LwM2M 对象/资源模型缺失**：`3.1` 与 `3.3` 缺少 LwM2M 标准化对象（Security、Server、Device、Connectivity Monitoring、Firmware Update 等）的形式化或结构化描述。
4. **跨协议运行时语义缺失**：`3.7 系统运行时语义` 未覆盖 Matter/Thread/LwM2M 的设备上线、密钥协商、状态同步、固件更新等运行时行为。
5. **形式化工件缺失**：当前 `tools/` 中无针对 Matter/Thread/LwM2M 的 TLA+/UPPAAL/Alloy 模型。

## 5. 与 MQTT/CoAP 专题的协同

- `8.网络系统/8.8 综合专题与前沿展望/8.8.35 物联网协议：MQTT v5.0 与 CoAP.md` 已覆盖 MQTT/CoAP 的架构、对比与安全分析，并提及 CoAP 常与 LwM2M 结合。
- 建议在 Phase 2 扩展 `8.8.35` 或新建 `8.8.x` 专题，将 Matter（应用层互操作）、Thread（链路/网络层）、LwM2M（CoAP 上的设备管理）与 MQTT/CoAP 并置对比，形成 IoT 协议全景。
- 在 `3.1 知识梳理/3.1.1 基本概念.md` 的“通信协议形式化定义”与“协议栈层次表”中增加 Matter/Thread/LwM2M 条目。
