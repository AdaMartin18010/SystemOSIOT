## 1. 标准概述

| 属性 | 内容 |
|---|---|
| 标准名称 | ISO/IEC/IEEE 42010:2022 — Software, systems and enterprise — Architecture description |
| 发布机构 | ISO / IEC / IEEE |
| 版本 | 2022（Second edition，2022-11 发布） |
| 官方链接 | <https://www.iso.org/standard/77394.html> |
| 访问日期 | 2026-07 |
| 适用范围 | 软件、系统与企业架构描述的结构与表达；定义架构描述（AD）、关注点（Concern）、视点（Viewpoint）、视图（View）、模型种类（Model Kind）及架构描述框架（ADF）、架构描述语言（ADL）等概念 |

> 权威说明：该标准区分“被关注实体的架构”与“表达该架构的架构描述（AD）”，并建立概念模型以支持利益相关者关注点向视图和模型的追溯。来源：[ISO/IEC/IEEE 42010:2022(en)](https://www.iso.org/obp/ui/#iso:std:iso-iec-ieee:42010:en)、[IEC Webstore](https://webstore.iec.ch/en/publication/80194)。

## 4. 关键覆盖缺口

1. **视点-视图-模型种类三层结构缺失**：`1.5 多表征` 当前以“概念图/结构表/数学符号”等表征类型组织，未引入 42010 的视点（Viewpoint）作为关注点的封装、视图（View）作为视点实例、模型种类（Model Kind）作为视图构成约定。
2. **架构决策与理由未显式化**：`01-system-theory/02-architecture/05-architectural-decision/` 尚为规划目录，缺少架构决策记录（ADR）与决策理由的条款级映射。
3. **多视图一致性未形式化**：`1.6 形式语义` 未覆盖不同视图/模型之间的对应关系（Correspondence）与一致性规则，难以支撑跨表征的语义验证。
4. **缺少标准 ADL/框架引用**：项目未引用 SysML v2、ArchiMate、UAF 等可作为 42010 ADL/AF 的具体实现。

## 5. 与 SysML v2 / 多表征的协同建议

- 在 `1.5 多表征` 中新增“视点-视图模型”子节，按 42010 定义重新组织现有概念图、结构表、数学符号。
- 在 `01-system-theory/02-architecture/` 中创建 `architecture-description-viewpoints.md`，定义项目采用的视点集合（如功能视点、运行时视点、安全视点、演化视点）。
- 在 `1.6 形式语义` 中补充视图间对应关系的形式化规约，建议以 TLA+/Alloy 表达一致性规则。
- 与 `1.0.3 SysML v2 / KerML 映射` 联动，将 SysML v2 的 `View`、`Viewpoint`、`Concern` 元素作为 42010 ADL 的具体载体。
