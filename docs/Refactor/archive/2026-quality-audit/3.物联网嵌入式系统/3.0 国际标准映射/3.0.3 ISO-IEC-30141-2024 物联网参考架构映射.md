## 4. 关键覆盖缺口

1. **30141 多视图架构未对齐**：`3.1.1 基本概念.md` 使用“感知层/网络层/应用层”三层架构，与 ISO/IEC 30141:2024 的参考架构视图（如业务、功能、网络、数据、安全等）未显式映射。
2. **Construction View / 设计模式缺失**：`3.3 形式化结构` 缺少面向 IoT 的构建视图、设计模式与参考实现的映射。
3. **Trustworthiness 覆盖空白**：`3.2 批判分析` 未系统覆盖 30141 的安全、隐私、可靠性、弹性、可用性、可维护性等可信维度；`3.7` 也未将可信属性纳入运行时语义。
4. **缺少 30141 到具体协议/接口的追溯**：如 30141 网络视图与 MQTT/CoAP/Thread/Matter 等协议的关系未在项目中显式建立。

## 5. 与 ISO/IEC/IEEE 15288 / 42010 的协同

- 在 `3.1 知识梳理` 中新增“ISO/IEC 30141:2024 参考架构视角下的 IoT 概念模型”章节，将三层架构扩展为与 30141 一致的多视图架构。
- 在 `3.3 形式化结构` 中补充 IoT 构建视图与设计模式，建议以 Alloy/TLA+ 表达模式约束。
- 在 `3.2 批判分析` 中新增可信性批判专题，对照 30141 Trustworthiness 条款。
- 与 `1.0.4 ISO/IEC/IEEE 42010:2022 架构描述映射` 联动，将 30141 的 IoT 参考架构视图作为 42010 视点-视图模型的 IoT 领域实例。
